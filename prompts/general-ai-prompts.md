# 🤖 General AI Prompts

A collection of practical AI prompts for learning, productivity, writing, coding, analysis, and everyday tasks.

## 🧠 Learning Prompt

```text
You are an expert teacher.

Explain [TOPIC] to me in simple language.

Requirements:
- Assume I am a beginner.
- Explain step by step.
- Give 3 real-world examples.
- Mention common mistakes.
- End with a short summary.
```

## ✍️ Writing Prompt

```text
You are a professional writer.

Write a [TYPE OF CONTENT] about [TOPIC].

Requirements:
- Use clear and simple language.
- Make it engaging and professional.
- Keep it concise.
- Use headings where useful.
- Provide the final answer ready to use.
```

## 💻 Coding Prompt

```text
You are an experienced software developer.

Help me with [CODING TASK].

Context:
[ADD YOUR PROJECT DETAILS]

Requirements:
- Explain the solution step by step.
- Provide clean and readable code.
- Explain the important parts.
- Mention possible errors and how to fix them.
```

## 📊 Analysis Prompt

```text
You are an expert analyst.

Analyze the following information:

[PASTE INFORMATION]

Requirements:
- Identify the key points.
- Explain important patterns.
- Mention possible problems.
- Give practical recommendations.
- Present the result in a clear format.
```

## 🚀 Productivity Prompt

```text
You are a productivity expert.

Help me achieve this goal:

[GOAL]

My available time:
[TIME]

Requirements:
- Create a practical step-by-step plan.
- Prioritize the most important tasks.
- Keep the plan realistic.
- Include a simple daily checklist.
```

## 🎯 Prompt Engineering Formula

A strong AI prompt can include:

- Role
- Task
- Context
- Requirements
- Output Format
