# 🤖 AI Prompt Toolkit

A practical collection of AI prompts, prompt engineering techniques, templates, and examples.

## 📌 About This Project

This project contains useful prompts and techniques for getting better results from AI tools.

## 🧠 Prompt Engineering Basics

A good prompt should include:

- Role
- Task
- Context
- Requirements
- Output Format

## 🧩 Prompt Template

```text
You are an expert in [TOPIC].

Task:
[DESCRIBE WHAT YOU WANT]

Context:
[ADD RELEVANT INFORMATION]

Requirements:
- [REQUIREMENT 1]
- [REQUIREMENT 2]

Output:
Provide the answer in [DESIRED FORMAT].
```

## 💡 Example

### Basic Prompt

```text
Explain artificial intelligence.
```

### Better Prompt

```text
You are an AI tutor.

Explain artificial intelligence to a beginner using simple language.

Give 3 real-world examples and finish with a short summary.
```
